3-Axis Magnetic Field Simulation System

  • MATLAB/Simulink
  • STM32
  • PID Control
  • SGP4
  • IGRF

Project Overview

Designed and developed a 3-axis magnetic field simulation system using Octagonal Helmholtz Coils for satellite ADCS Hardware-in-the-Loop (HIL) testing.

Key Features

  • Developed magnetic field models based on the Biot-Savart Law
  • Integrated SGP4 orbit propagation and IGRF models
  • Implemented PID control on STM32 Nucleo-F439ZI
  • Performed sensor calibration and system validation
  • Developed a central control interface using Simulink

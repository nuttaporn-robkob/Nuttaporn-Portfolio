Automatic Weight Measurement and Sorting System using Load Cell

An Arduino-based weighing and weight-sorting system that measures object weight with a strain-gauge load cell and HX711 amplifier, processes the sensor signal, and uses the measured value to control a servo mechanism.

  • Arduino
  • Load Cell
  • Strain Gauge
  • HX711
  • Servo Motor
  • Calibration

Project at a Glance

GoalMeasure object weight and use predefined weight ranges to drive a sorting mechanism.
ControllerArduino microcontroller for sensor reading and control logic.
SensingStrain-gauge load cell with an HX711 signal-acquisition amplifier.
ActuationServo motor mechanism controlled according to the measured weight.

System Flow

1. ObjectPlaced on the weighing structure
2. Load CellDetects force through strain-gauge deformation
3. HX711Amplifies and acquires the load-cell signal
4. ArduinoReads and processes the sensor value
5. Weight DecisionCompare the measured value with reference ranges
6. ServoMoves the sorting mechanism

Key Features

  • Load-cell-based weight measurement.
  • HX711 amplifier for load-cell signal acquisition.
  • Arduino-based sensor data processing.
  • Weight-based servo motor control.
  • Comparison of measured weight against reference values.
  • Load-cell calibration and testing.
  • Mechanical structure designed to support and protect the load cell.

Engineering Focus

This project demonstrates the integration of sensing, embedded programming, actuation, calibration, and mechanical design in one mechatronics system. The important part was not only reading a sensor value, but turning that measurement into a physical control action through the servo mechanism.

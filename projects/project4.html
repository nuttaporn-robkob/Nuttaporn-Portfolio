Servo-Controlled Two-Legged Walking Robot

  • Arduino
  • Servo Motor
  • Bluetooth
  • MIT App Inventor
  • Robotics
  • Embedded Systems

Project Overview

Designed and developed a two-legged walking robot controlled by servo motors. The robot uses multiple servo motors to control the hip, knee, and foot joints, enabling forward and backward walking movements. Bluetooth communication was implemented to receive movement commands from a mobile application developed with MIT App Inventor.

Key Features

  • Multi-servo control for coordinated leg movements
  • Forward, backward, and stop movement functions
  • Bluetooth communication between the robot and mobile application
  • Mobile control interface developed with MIT App Inventor
  • Servo synchronization for smoother walking motion
  • Mechanical balance and weight distribution testing
  • Troubleshooting and mechanical adjustments during prototype testing

My Contribution

  • Developed the servo motor control and walking sequence
  • Implemented Bluetooth command communication
  • Developed movement functions for forward, backward, and stop operations
  • Tested robot movement and identified mechanical/balance issues
  • Adjusted the robot's structure and weight distribution to improve walking performance

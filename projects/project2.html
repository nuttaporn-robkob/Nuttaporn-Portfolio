Bilingual AI Voice Assistant — ToTo Chatbot

A Thai-English conversational AI assistant built with Python and Streamlit. The application combines a Gemini language model with speech recognition and text-to-speech so users can interact through both text and voice.

  • Python
  • Streamlit
  • Google Gemini API
  • Speech Recognition
  • gTTS
  • Thai / English
Live Demo

Project at a Glance

GoalCreate an interactive bilingual assistant that can accept text and voice input.
My FocusAI integration, voice interaction, application flow, testing, and user-facing interface.
AI EngineGoogle Gemini API through the Google GenAI Python client.
InterfaceStreamlit web application with session-based conversation history.

How the System Works

1. User InputText or microphone input
2. ProcessingSpeech-to-text when voice is used
3. GeminiGenerate a Thai/English response
4. Chat StateKeep conversation messages in session state
5. Voice OutputConvert the response to audio with gTTS
6. Streamlit UIDisplay the conversation and controls

Key Features

  • Thai-English conversational interaction.
  • AI response generation using the Gemini API.
  • Voice input through speech recognition.
  • Text-to-speech output using gTTS.
  • Conversation history maintained with Streamlit session state.
  • Special commands such as time and name handling.
  • Error handling for missing API configuration and voice-generation failures.
